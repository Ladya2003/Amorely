# ТЗ: этап `words` (Doodle Jump, слова)

Вход: кнопка «Дальше» из общего зала `guides` (оба `escaped` **и оба online**). Иначе `games.cliff.waitPartner`. Выход: оба на вершине трека → заглушка до `camp` (тоже только оба online). Один этап, тестовый сброс как `reset-guides`.

Новый чат: `@docs/cliff-climb-roadmap.md` + этот файл. **Только этот этап.**

## Экран

Один мир. A (owner) слева, B (partner) справа. Камера одна, скролл вверх. Платформы с **отскоком**. Кнопки: прыжок, влево, вправо.

Мир (не CSS vh): ширина **100**, высота кадра **100**, зазор платформ **22**, платформ **24** (старт + 23 отскока до верха). Чекпоинты на платформах **8 / 16 / 22**. Финиш — верхняя платформа.

## Топливо (личное)

- Старт **12**, потолок бака **12**.
- Отскок **−1**.
- Фраза партнёру **+4** (полный бак = 3 фразы).
- 0 топлива у одного — если **оба в сцене** и никто ещё не на финише: оба на **последний общий** чекпоинт (`min` индексов), топливо снова 12. Фразы забега не сбрасывать.
- Если партнёра нет: проверки разрыва и парного сброса нет; без топлива просто не отскочить.

Без фраз до вершины не хватает: 23 отскока > 12.

## Чекпоинты и фразы

- **3** чекпоинта (плюс старт = 0).
- **4** ключа в локалях: `cheer`, `believe`, `together`, `proud`. Одну и ту же **нельзя** повторно на этапе.
- Фраза поднимает топливо **получателю**.
- Не шлагбаум: можно пройти чекпоинт молча. Кнопка «подбодрить» доступна всегда, пока есть неиспользованные фразы.

Подбадривание — **только здесь**, не на шарах.

## Разрыв

Оба на общий чекпоинт, если разрыв по **Y в мире** больше **одной высоты кадра (100)**. Не `100vh`.

Камера: общее окно, якорь — нижний из двоих (или один, если партнёра нет).

Если один уже на финише — парный сброс разрыва/топлива не трогает финишёра.

## Провал / офлайн

Своё (прыжки, отскоки) можно делать без партнёра. Позиции копятся.

На `camp` / «Дальше» — только когда оба на вершине **и оба online**. Иначе «подожди партнёра».

## Реализация

- Сцена `words`, высота 220.
- Сокеты/REST: `words/enter`, `words/sync` (`x`, `y`, `bounce`), `words/phrase`, `reset-words`.
- Сервер: Y вверх только через `bounce`; отскок тратит топливо; фразу не принимать повторно; разрыв считать в мировых единицах.
- i18n все 8 локалей.
- Не трогать лабиринт кроме «Дальше» → enter words.

## Не делать

- Свободный текст фраз на сервер.
- Подбадривание на шарах.
- Пускать в лагерь по одному.
