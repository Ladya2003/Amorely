# ТЗ: этап `balls` (дорожка с шарами)

Новый чат: `@docs/cliff-climb-roadmap.md` + этот файл. **Только этот этап.** Вход — кнопка «Дальше» с канатов (`ropes` cleared). Выход — катсцена скатывания в пещеры → сцена `caves` (если `caves` ещё нет — заглушка «дальше» как на канатах).

Тестовый сброс этапа, по образцу `reset-ropes`.

## Правила

- У каждого **5 шаров**. Броски **одновременно**, свои шары.
- Сила + траектория, качение 1–2 с. Не путать с мостом (мост = лунка).
- Зоны от ближней к дальней: **10 / 20 / 30 / 40**. Промах / не докатил до первой зоны — 0, шар сгорел.
- Очки **складываются на пару**.
- Этап пройден, когда **оба потратили по 5 шаров** и сумма **≥ 170**.
- Подбадривания нет.

Почему 170: 5×20×2 = 200 «в среднем»; 170 чуть ниже, справедливо. Один игрок максимум 5×40 = 200, но без пяти бросков партнёра этап **не** закрывается.

## Реализация

- Сцена `balls`, высота ~160.
- Сокеты/REST по образцу `throw` / `ropes/jump`. Сервер считает очки и `ballsRemaining`, не доверять клиентскому итогу вслепую (как минимум проверить диапазон зоны).
- i18n все 8 локалей.
- Не трогать логику канатов кроме «Дальше» → enter balls.

## Партнёр офлайн

Можно бросить свои 5. Счёт копится. Условие этапа — оба потратили по 5 и сумма ≥ 170.

**На `caves` не переходить**, пока оба не online. Если своё уже сделано, а партнёра нет — «подожди партнёра», без катсцены падения.
