# ТЗ: этап `camp` (лагерь: золото, алмазы, ботинки)

Вход: `words` cleared. Выход: оба в ботинках (любой ур.) → `climb`. Меч/лук не обязательны. Тестовый сброс.

## Шахта

Золото и алмазы, валуны как на хабе. Добыча **личная**.

На фоне виден финальный узкий подъём.

## Магазин

| Слот | Кто | Ур. | Цена (личное золото + личные алмазы) | Обязателен |
|------|-----|-----|--------------------------------------|------------|
| Ботинки с шипами | каждый / можно **подарить** | 1 | 6 золота + 4 алмаза | да (хотя бы 1 ур. на ногах) |
| | | 2 | 12 + 8 | нет |
| | | 3 | 20 + 14 | нет |
| Меч | только **первый**, кто купил меч | 1 / 2 / 3 | 8+4 / 14+8 / 22+14 | нет |
| Лук | только тот, кто **не** взял меч | те же цены | нет |

Апгрейд ботинок: доплатить разницу или полная цена уровня — **доплатить разницу**.

Подарок ботинок: снять с инвентаря дарителя (купленную пару) → у получателя. Нельзя отдать единственные, если даритель сам без ботинок и хочет остаться без входа (получатель может войти, даритель нет — ок).

Кто купил меч первым — флаг на забеге; второй видит только лук.

## Вход на подъём

Оба имеют ботинки 1+ **и оба online**. Иначе «подожди партнёра». Оружие не проверять.

Выше уровень ботинок → на `climb` полоска 25 / 35 / 45 с.
